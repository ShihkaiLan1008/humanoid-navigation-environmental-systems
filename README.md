# 機器人導航研究：環境系統的延伸思考

**Shih-Kai Lan（藍詩凱）｜工程與生物環境系統閱讀版**

這份作品集整理我參與的人形機器人模擬研究，並說明我希望如何將定位、感測與實驗評估的學習，延伸到環境系統問題。研究本身是導航模擬；環境監測與巡檢是未來希望探索的應用方向。

## 我研究了什麼？

**機器人抵達目標後，系統是否有足夠的定位信心確認它已經抵達？**

我於 2026 年夏季開始參與 Georgia Tech LIDAR 團隊的研究，在 Ye Zhao 教授的指導及 Zhenyu Wu 的直接指導下，參與既有導航系統的評估。我依指定任務組織 AI 協助的工作流程，檢視模擬影片與量測資料，整理結果並與團隊溝通。團隊提供底層控制器、導航與定位方法、模型及參考資料；程式實作、模擬操作與分析使用了大量 Codex 協助。

## 已保存的研究結果

四次完成的導航模擬均進入實際目標區域，但只有一次通過系統的 95% 聯合抵達信心門檻。這個差異讓我學到：看見機器人到達，與系統有足夠證據確認到達，並不是同一件事。

| 模擬場景 | 最終目標距離 | 聯合抵達信心 | 系統判定 |
| --- | ---: | ---: | --- |
| 原始房間 | 7.31 cm | 93.35% | 未確認抵達 |
| 中央障礙島 | 6.41 cm | 92.41% | 未確認抵達 |
| 偏置開口 | 4.07 cm | 91.89% | 未確認抵達 |
| 交錯隔板 | 4.16 cm | 96.04% | 確認抵達 |

每張地圖僅一個完成的隨機種子試驗，且原始地圖與新地圖的時間限制不同。上述是初步模擬個案，不能當作一般成功率或真實場域可靠度。

我較早也參與訓練環境重建、足部追蹤獎勵修改及 500 次迭代的診斷訓練。我指出不同平行環境數導致訓練樣本量不一致，需匹配條件才能公平比較；現有結果未證實足部追蹤改善。

## 為什麼與生物環境系統工程有連結？

環境量測除了數值本身，也需要知道資料來自哪裡。若未來使用移動平台輔助巡檢或量測，定位的不確定性就會影響資料與地點的對應。因此，我希望把目前對地圖、定位與系統信心的學習，延伸到「如何讓環境監測資料的位置與品質值得信任」。

這是從現有研究提出的學習方向，並非已完成的環境監測成果。目前未測試生態保育、水質、土壤、農田或災害場域，也未證明人形機器人是這些任務的最佳工具。未來仍須依任務需求選擇平台，補足環境科學與量測知識，再以實驗驗證。

## 我的工程學習

- **把問題轉成可檢查的實驗：** 定義場景、量測指標與比較條件。
- **檢查資料與結論是否一致：** 區分真實位置、系統信心與判定結果，保留不利結果與限制。
- **整合工具並留下紀錄：** 在導師與 AI 協助下重建環境、檢視結果及整理可追查的研究資料。
